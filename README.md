# Personal-Podcast-Manager 🎙️
A web-based podcast management app to organize podcasts, track listening progress, bookmark episodes, and manage a personal listening queue. Built with HTML, CSS, JavaScript, Python, FastAPI, and SQLite.

# Basic Architecture 🎙️
1. Frontend: The user adds a podcast using a form.
2. Backend API: FastAPI validates the input and processes the request.
3. Database: SQLite saves the podcast so it remains after the page is refreshed.
4. Response to frontend: The UI updates to show the saved podcast or an error message.
